🎓 College FAQ Chatbot

Project Description

The College FAQ Chatbot is a Python-based application developed as part of the CodeAlpha Artificial Intelligence Internship. It answers frequently asked college-related questions using Natural Language Processing (NLP).

Features

- Answers frequently asked questions.
- NLP-based question similarity matching.
- TF-IDF and Cosine Similarity.
- Keyword-based matching for common questions.
- Interactive Streamlit chatbot interface.
- Chat history and clear chat option.

Technologies Used

- Python
- Streamlit
- Scikit-learn
- NumPy
- Natural Language Processing (NLP)

Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

Project Structure

- app.py – Chatbot interface
- chatbot.py – NLP matching logic
- faqs.json – FAQ question-answer dataset
- requirements.txt – Project dependencies
